
The **ka9q-radio** is the personal project of Phil Karn, to create a C code to process wide swaths of radio spectrum in real time.  It creates packages of spectrum that can be post processed by decodes for specific signal modulation.  

**ka9q-radio** uses a verity of usb hardware radio devices to collect  signals from an antenna. It is designed to work at a fixed real time cadence and write the data into convenient block lengths.   These block files are then fed to a collection of signal decoders.
This partitioning is important as the samples are time critical to avoid signal loss.
